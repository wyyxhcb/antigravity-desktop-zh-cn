# Antigravity 桌面版简体中文语言包

版本 **1.4.0 扩展版**，适配 **Windows / Antigravity 2.28.1、2.28.2、2.29.0、2.31.2、2.32.1**。非 Google 官方产品。

本机 Antigravity 2.28.2 已安装此扩展版。这是可恢复的本地汉化补丁，不是 VSIX，不通过应用内插件市场安装。

## 翻译范围

- 5,405 条静态翻译与 522 组动态匹配规则。
- 首页、工作区、侧边栏、设置说明、快捷键、通知、模型、用量、自动化、自定义、插件、账户和权限界面。
- 时间、数量、版本、进度等动态文案；右键菜单、系统托盘、退出提示和初次启动向导。
- 对当前程序内置界面资源逐项核对，并补充版本新增文案。

聊天正文、代码、输入值、已有对话标题、文件内容和嵌入页面受保护。模型及产品名称、快捷键符号、路径、命令和技术标识保留原文。后端错误详情、第三方插件自己生成的页面以及尚未遇到的动态文案不保证全部覆盖。此包不改变 AI 回答的语言。

## 安装或升级

1. 完整解压压缩包，保留全部文件。
2. 保存工作并完全退出 Antigravity；如果仍在系统托盘运行，请选择退出。
3. 若已安装旧版语言包，先双击 **恢复英文.cmd**。
4. 双击 **安装中文.cmd**，看到“安装完成”后重新打开应用。

需要 Python 3.9 或以上，本机已安装 Python 3.13。无需额外依赖或联网。双击 **检查状态.cmd** 可查看安装状态。

## 恢复英文

完全退出应用，双击 **恢复英文.cmd**，再打开应用。原文件备份保留在安装目录的 resources 文件夹中，名称以 app.asar.zh-cn.original. 开头。

安装器不会强行结束应用。安装前检查版本、界面加载文件及原生界面模块的校验值；备份并校验原文件后才替换资源。恢复时再次核对备份及当前程序，避免覆盖官方更新或其他工具所作的修改。

## 更新和兼容性

官方自动更新保持开启。更新可能覆盖本补丁；更新后请使用适配相应版本的语言包。不要通过修改版本号或校验值强行安装。

不改动程序 EXE、用户账户、权限配置、代理或自动更新设置。翻译模块离线运行，不发送数据，也不增加应用接口；原生右键菜单仍调用原有接口，只翻译显示标签并保留操作 ID。

## 文件说明

- manage.py：安装、检查、备份、恢复与构建工具。
- localizer.js、renderer.js：本地文字匹配及界面翻译。
- zh-CN.json、patterns.json、source-text.json：词典、动态规则和内置界面文案清单。
- native-patches.json：经过版本校验的原生界面文字修改。
- 验证报告.md：测试范围与限制。

自定义路径可使用：python manage.py install --app-dir "D:\Apps\Antigravity"。将 install 换成 status 或 restore 可检查或恢复。

若出现锁文件提示，先确认其他安装器均已退出，再处理安装目录 resources 下的 .antigravity-zh-cn.lock。请勿在安装仍在运行时删除锁文件。
